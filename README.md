Customer Churn Predicition Project

This projects focuses on predicting customer churn in telecom using machine learning techniques. It was made using Python and libraries: scikit-learn, pandas, matplotlib and numpy. It contains sections that have their descriptions on what is happeninng in each.

The purpose of this project is to identify the risk of customer churns for buisness companies. From this they can see where they are making problems and prevent furthers churns. Results of the project are supported by metrics and data that shows the comparision for Logistic Regression and Random Forest which are two diffrent models that show two aproaches for the problem.
